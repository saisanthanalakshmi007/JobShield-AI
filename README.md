# JobShield AI

### AI-Powered Recruitment Scam Detection & Protection Platform

JobShield AI is a proposed web-based platform designed to help students, fresh graduates, job seekers, and freelancers identify potentially fraudulent job postings and recruitment messages.

The system will combine AI/NLP analysis with rule-based scam indicators to generate an explainable risk assessment and provide safety and verification guidance.

## Proposed Features

- Job posting and recruitment message analysis
- Screenshot and PDF input
- AI/NLP-based scam analysis
- Rule-based scam indicator detection
- Explainable risk scoring
- Low Risk / Suspicious / High Risk classification
- Safety and verification recommendations
- Community reporting of suspicious postings

## Planned Technology Stack

- Frontend: HTML, CSS, JavaScript / React
- Backend: Python, FastAPI
- AI/NLP: NLP/LLM analysis and rule-based detection
- Database: Firebase / Supabase
- Deployment: Cloud-based web deployment
